Krita Studio Kit · Booklet 1

Draw it, move it, post it.
Krita for 2D animation and short videos

For people who make hand-drawn posts, drawing reveals, poem and story animations, and Reels or Shorts. No experience needed.

FreeKrita costs nothing, forever
1080×1920the size of a Reel or Short
12 fpsenough for hand-drawn motion
30 daysfrom first line to a 10-second story

Written for Krita 5.2 and newer. Menu names can move a little between versions. If a menu is not where this booklet says, look in the nearby menus or use the search in Help.

1Install Krita on Linux

Goal: Krita opens on your computer. Takes about 10 minutes.

Flatpak: an app store system for Linux. It keeps each app in its own box.
AppImage: one file that is the whole app. You download it and run it. Nothing to install.

Way A: Flatpak (easiest updates)

  1. Open a terminal (Ctrl+Alt+T on most systems).
  2. If Flatpak is new to you, add the Flathub store once: 
    flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  3. Install Krita. The download is about 200–300 MB. 
    flatpak install flathub org.kde.krita
  4. Open it from your app menu (search "Krita"), or type: 
    flatpak run org.kde.krita

Way B: AppImage from krita.org

  1. Go to krita.org → Download → Linux, and save the .appimage file (about 200–300 MB).
  2. Make it runnable, then start it: 
    chmod +x ~/Downloads/krita-*.appimage
~/Downloads/krita-*.appimage
  3. Keep the file in a safe folder (for example ~/Apps). That one file is Krita.
Which one? Pick Flatpak if you want updates to come by themselves. Pick the AppImage if you want the newest version from krita.org right away.

First-time setup (5 minutes, saves hours)

  1. Tablet: if you use a pen tablet, test pressure in Settings › Configure Krita › Tablet settings. Draw on the test area. Lines should get thicker when you press harder.
  2. Autosave: in Settings › Configure Krita › General, check the autosave time (every few minutes is good).
  3. Language and theme: Settings › Switch Application Language and Settings › Themes.
  4. Memory: in Settings › Configure Krita › Performance, give Krita a fair share of RAM. Animation uses a lot.
Not sure Flatpak is installed?

Type flatpak --version. If you see a number, it is there. If not, on Ubuntu-like systems run sudo apt install flatpak, then log out and in again. Your distribution's docs have the exact steps.

2A tour of the screen

Goal: know the five areas you will use every day.

Docker: a small panel on the side of the screen (Layers, Brush Presets, Timeline…). You can move, close and re-open them.
Workspace: a saved arrangement of dockers for one kind of job.

Switch to the Animation workspace

  1. Open Window › Workspace › Animation.
    Or click the workspace button at the top right of the window and pick Animation.
  2. The Timeline appears at the bottom, with Onion Skins and other animation dockers nearby.
  3. Lost a docker? Bring it back from Settings › Dockers.
Tip: press Tab to hide all dockers and see only the canvas. Press it again to bring them back.

3A new document for animation

Goal: the right size, speed and length before you draw anything.

Frame: one picture in the animation.
fps (frames per second): how many pictures play each second.
DPI: dots per inch. It only matters for paper printing, not for video.
  1. File › New (Ctrl+N) → Custom Document.
  2. Width 1080, Height 1920 (Reels). Or 1920 × 1080 for YouTube.
  3. Resolution: 72 for video. Use 300 only for a picture you will print, like a book page.
  4. On the Content tab, pick a white or paper-coloured background. Click Create.
  5. Go to the Animation workspace (chapter 2). At the top of the Timeline, set the frame rate (FPS) to 12 or 24.
  6. Set the clip length with the Start and End frame numbers. At 12 fps, 10 seconds = frames 0 to 119.
  7. Save now as a .kra file (Ctrl+S). It keeps all your layers and frames.
Length in frames = seconds × fps  ·  10 s × 12 fps = 120 frames  ·  15 s × 24 fps = 360 frames
Older Krita? Where the frame rate lives

In Krita 5.2 the playback buttons, FPS and Start/End sit in the header of the Timeline docker. In older versions they were in a separate Animation docker (Settings › Dockers › Animation). Same settings, different place.

Why not draw at 4K?

Every frame is a full picture in memory. A 4K canvas with 120 frames and 5 layers can fill your RAM and make playback stutter. 1080 × 1920 is what Instagram and YouTube Shorts show anyway.

4Brushes for children's-book art

Goal: four brushes you love, and smooth wobble-free lines.

Brush preset: a saved brush, with its shape, size and texture ready to use.
Stabilizer: a helper that smooths your shaky hand into a calm line.

Find the built-in presets

  1. Press B for the Freehand Brush tool.
  2. In the Brush Presets docker, type in the search box: pencil, ink, water, airbrush.
  3. Try each one. Good starters in the default set are a pencil (for example Pencil-2), a fineliner or G-pen ink, a "Water C" style wet brush, and a soft airbrush. Names vary a little by version.
  4. Right-click the canvas: a ring of favourite brushes pops up. Drag your four favourites into a tag so they show there.

Turn on the stabilizer

  1. With the brush tool (B), open the Tool Options docker (Settings › Dockers › Tool Options if hidden).
  2. Set Brush Smoothing to Stabilizer.
  3. Raise Distance for smoother lines (try 30–50). Higher = smoother but the line trails behind your pen.
  4. Turn it back to None for quick sketching.

Keys you will press 1000 times

B brushE eraser on/off[ smaller] biggerCtrl+Z undoSpace+drag panCtrl+Space+drag zoom
Children's-book look: pencil lines + flat watercolour fills + soft airbrush on the cheeks. Use a warm paper colour, not pure white, for the background.
Note: E is a switch, not a tool

Pressing E turns the current brush into an eraser of the same shape. Press it again to paint. If your brush "won't paint", check you did not leave eraser mode on.

5Layers

Goal: change one thing without breaking the rest.

Layer: a clear sheet. You stack sheets; the top ones cover the bottom ones.

Set up the stack

  1. Add a paint layer: Insert, or the + button in the Layers docker. Double-click a name to rename it.
  2. Make three layers: Background, Lines, Colour. Drag Colour under Lines, so the lines stay crisp on top.
  3. Select Lines and Colour, press Ctrl+G to put them in a group. Name it after the character.
  4. The eye icon hides a layer. The lock icon stops changes.

The Inherit Alpha colouring trick

Alpha: how see-through a pixel is. "Inherit alpha" = borrow the see-through shape of the layers below.
  1. Inside the character group, add a new layer above Colour. Call it Shading.
  2. Click the α (Inherit Alpha) icon on the Shading layer in the Layers docker.
  3. Paint shadows or a soft airbrush blush. It only appears where the group's layers below have paint.
Clipping, Krita style: Krita has no separate "clipping mask". Inherit Alpha inside a group is clipping. Layer › Group › Quick Clipping Group (Ctrl+Shift+G) builds the group and the inherit-alpha layer for you.
Inherit Alpha vs Lock Alpha

Lock Alpha (the checkerboard lock) lets you repaint only the pixels already on that same layer. Great for recolouring a line. Inherit Alpha borrows the shape of everything below it in the group. That is why the group matters: outside a group, the background would count too, and the trick stops working.

6Animation basics

Goal: a bouncing ball that feels alive. Your first real animation.

Keyframe (Krita often says just "frame"): a cell in the timeline that holds a drawing.
Hold: a drawing that stays on screen for more than one frame.
Onion skin: faint ghosts of the frames before and after, so you can see where to draw next.

Make frames

  1. In the Animation workspace, select your layer. Click a cell in the Timeline.
  2. Right-click the cell → Create Blank Frame for a new empty drawing, or Create Duplicate Frame to copy the drawing you see and change it a little.
  3. Move between frames with . (next) and , (previous). Jump between drawings with Alt+. and Alt+,.
  4. Press the Play button in the timeline header to watch. Press it again to stop.
  5. Optional: turn on auto-frame mode (the button with a frame/key icon in the timeline header). Then drawing on an empty cell makes a new frame by itself.

Holds: "on 1s" and "on 2s"

  1. To hold a drawing longer, drag the keyframe to the right, leaving empty cells behind it. Empty cells after a drawing keep showing it.
  2. Or right-click a frame → the hold frames options (insert or remove holds) to push the next drawings along.
  3. At 24 fps, put a new drawing every 2nd frame. That is "animating on 2s".

Onion skin

  1. Turn onion skin on for a layer with the onion icon in the Layers docker (or the layer's row in the Timeline).
  2. Open the Onion Skins docker (Settings › Dockers › Onion Skins) to choose how many frames before and after, and how faint.

The 4 principles that matter first

Timing & spacingHow many frames (timing) and how far apart the drawings are (spacing). Far apart = fast.
Squash & stretchFlatten on impact, stretch when fast. Keep the amount of "stuff" the same.
AnticipationA small move the other way before the big move. Crouch before a jump.
Ease in / ease outStart slow, go fast, end slow. Put more drawings near the start and end.

Exercise: the bouncing ball (12 fps, 1 second)

  1. New 1920 × 1080 file, 12 fps, frames 0–11. Draw a floor line on the Background layer.
  2. Add a layer "Ball". On frame 0 draw the ball at the top left. Turn on onion skin.
  3. On frame 6 draw the ball touching the floor, squashed flat.
  4. On frame 11 draw it back up near the top, a bit to the right and a bit lower.
  5. Fill in between: frames 1–2 close together (slow at the top), frames 4–5 far apart and stretched (fast near the floor).
  6. Press Play. Too floaty? Remove a frame near the top. Too stiff? Add one.
What about the other 8 principles?

The full list (from Disney's animators) also has staging, straight-ahead vs pose-to-pose, follow-through, arcs, secondary action, exaggeration, solid drawing and appeal. Learn them after your first ten animations. You are already using arcs in the ball.

7Tweening and a simple camera pan

Goal: move, grow and fade a drawing without redrawing it.

Tweening: you set a start and an end; the computer fills the frames "in between".
Transform mask: a layer helper that moves, scales or rotates its layer without changing the pixels.

Move or scale with a transform mask (Krita 5.2+)

  1. Draw your object (say, a moon) on its own layer. Draw it once only, on one frame.
  2. Right-click the layer → Add › Transform Mask.
  3. Select the mask. Go to frame 0. Press Ctrl+T (Transform tool) and place the moon where it starts. Press Enter.
  4. With auto-frame mode on, Krita makes a transform keyframe. If not, add one from the mask's row in the Timeline (right-click a cell).
  5. Go to frame 24. Transform again: move, scale or rotate. Enter. A second key appears.
  6. Play. The moon glides between the two keys.

Fade in or out (opacity keys)

  1. Select the layer. Go to the first frame of the fade.
  2. In the Timeline, add an opacity keyframe for the layer (right-click its row and look for the opacity key option; Krita 5 shows it as a channel under the layer). Set the layer opacity to 0% in the Layers docker.
  3. Go to the last frame of the fade. Set opacity to 100%. A second opacity key appears.

Make it feel natural: ease

  1. Open Settings › Dockers › Animation Curves.
  2. Select the keys and pick smooth / bezier interpolation for a gentle start and stop, or linear for a robot-even move.

A simple camera pan

  1. On the Background layer, zoom out and paint a long strip that goes past the canvas edges. Krita keeps the paint outside the edge.
  2. Add a Transform Mask to the background. Key it at frame 0 and slide it left at the last frame.
  3. For depth (parallax), slide far things slowly and near things faster, each with its own transform mask.
Doesn't work? Common tween hiccups

Make sure the mask (not the layer) is selected when you transform. Make sure the layer has only one drawing in that range, or the drawing will change while it moves. In older Krita (before 5.2) transform masks could not be keyed this way; update Krita.

8Recipe: "the number 2 turns into a swan"

Goal: a 10–15 second drawing reveal for a Reel. Viewers watch the 2 become a swan.

Before you start

  1. Open the Recorder docker and press Record (chapter 9). Now you also get a free "process" video.
  2. New file 1080 × 1920, 12 fps, frames 0–143 (12 seconds).
  3. Layers: Background (paper colour), Number, Swan lines, Swan colour, Water.

Draw it frame by frame

  1. Frames 0–23 (2 seconds): on Number, draw a big, round "2" with an ink brush on frame 0. Let it hold so viewers read the number.
  2. Draw-on effect (optional): instead of showing the 2 at once, draw it in 4–6 parts. Each part on a new Create Duplicate Frame 2 frames apart. The 2 "writes itself".
  3. Frames 24–47: on Swan lines, Duplicate Frame every 2–4 frames and add one small detail each time: the eye, then the beak, then a feather curl on the neck.
  4. Frames 48–83: keep duplicating and adding: the wing on the bottom curve of the 2, the tail, ripples on Water. Use onion skin to keep lines in place.
  5. Frames 84–107: on Swan colour (below the lines), fill white and blush pink in 2–3 steps. Use Inherit Alpha for soft shading.
  6. Frames 108–143: hold the finished swan. Add a tiny loop: ripples moving, or 2–3 sparkles that blink.
  7. Play. Then export (chapter 10). Add a soft music bed and a text hook ("Can you draw a swan from a 2?") later (chapter 11).
Hook rule for Reels: something must change in the first second. Start the 2 already half-drawn, or show the finished swan for 0.5 s, then "rewind" to the 2.
More "number becomes…" ideas

1 → candle · 3 → bird or bee wings · 4 → sailboat · 5 → snail · 6 → snail or ear · 7 → flamingo leg · 8 → snowman · 9 → balloon on a string · 0 → sun with a face.

9The Recorder docker (timelapse)

Goal: a sped-up video of your drawing process, made while you draw.

Timelapse: a video that speeds time up. One hour of drawing becomes 30 seconds.
  1. Open Settings › Dockers › Recorder.
  2. Click its settings (gear) button. Check the folder where snapshots go, the capture interval (1 s is good), and the quality.
  3. Tick Record automatically if you want every drawing session recorded.
  4. Press the record button and draw. A dot shows it is recording. It only captures the canvas, not your menus.
  5. When done, click Export in the Recorder docker.
  6. In the export window, set the FPS (30 for social), the size (resize to 1080 × 1920 for a Reel), how long to show the finished picture at the end (3–5 s is nice), and the video format (MP4).
  7. Check the FFmpeg path is set (chapter 10), then export.
For "drawing process" Reels: aim for 20–40 seconds. If the timelapse is too long, raise the export FPS or the capture interval.
Disk space

Each snapshot is an image file. A long session at a 1 s interval can make thousands of them. Delete the snapshot folder after you have exported (the Recorder has a button to clear old recordings, or use your file manager).

10Exporting

Goal: an MP4 that Instagram, YouTube and WhatsApp accept, plus PNGs for later effects.

FFmpeg: a free helper program that turns pictures into video. Krita uses it to make MP4 and GIF.
H.264: the most common video "language" (codec). Every phone plays it.
PNG sequence: one PNG picture per frame, numbered 0001, 0002… No quality loss.

Set up FFmpeg once

  1. Recent official Krita builds usually come with FFmpeg built in. Try exporting first.
  2. If Krita says FFmpeg is missing, install it: sudo apt install ffmpeg (or your system's package manager).
  3. In the Render window, set the FFmpeg path to /usr/bin/ffmpeg. Find the real path with which ffmpeg.

Render an MP4 for a Reel

  1. Save. Then File › Render Animation…
  2. Choose Video. Container MP4, then open the video settings and pick H.264.
  3. Size 1080 × 1920. Frame rate: keep your document's (12 or 24). Instagram is happy with 24 or 30.
  4. Pick the output file name and folder. Click OK. Wait for the progress bar.
  5. Watch the file once in a video player before you post.

Export a PNG sequence (for effects later)

  1. File › Render Animation… → choose Image Sequence, format PNG.
  2. Pick an empty folder and a base name like swan_. You get swan_0000.png, swan_0001.png…
  3. Tip: you can tick both, so one render gives you the MP4 and the PNGs.
Why 12 fps becomes 24 or 30 on Instagram

A 12 fps video plays fine, but some apps re-encode it. If you see stutter, render at 24 fps: in a 12 fps animation, set the document to 24 fps and hold every drawing for 2 frames (on 2s). The look stays the same.

GIF tips

GIFs get big fast and have only 256 colours. Keep them short (2–4 s), small (720 px wide or less), and with flat colours. No sound.

11Adding effects and sound afterwards

Goal: a finished post with glow, paper texture, voice and music.

Effects: the Effect Blender app

  1. Open the companion web app in this kit: Effect Blender.
  2. Load your exported MP4 or PNG sequence, add looks (soft glow, paper grain, vignette), and export.

Voice and music: Kdenlive (free)

Video editor: an app that puts clips, sound and text on one timeline.
  1. Install: flatpak install flathub org.kde.kdenlive.
  2. New project → set the profile to vertical 1080 × 1920 at your frame rate.
  3. Drag your video into the Project Bin, then onto the timeline. Drag your voice recording and music below it.
  4. Lower the music under the voice (about −18 dB music vs voice near −6 dB is a safe start).
  5. Add a title for the hook in the first second. Render as MP4 (H.264 + AAC audio).
Lip sync or poem timing inside Krita

Krita can load one audio track to animate against: use the audio (speaker) control in the Timeline header to import a WAV or MP3. You will hear it while you scrub and play. Krita can include it in the render, but Kdenlive gives you more control for the final mix.

Common problems

The canvas is tilted or flipped

You rotated it with Shift+Space or mirrored it with M. Press 5 or use View › Canvas › Reset Rotation. Press M again to un-mirror. Your picture itself did not change.

The brush does not draw
  • Is the layer visible (eye on) and not locked?
  • Is a selection active elsewhere? Paint only lands inside it. Press Ctrl+Shift+A.
  • Is eraser mode on? Press E.
  • Is the brush opacity or size near 0 (top toolbar)?
  • Did you select a mask or a group instead of a paint layer?
  • Is Lock Alpha on for an empty layer?
Render Animation is greyed out or fails

Save the file first. Then check the FFmpeg path in the Render window (/usr/bin/ffmpeg; check with which ffmpeg). Flatpak Krita cannot see every system folder; if the path fails there, use its built-in FFmpeg or the AppImage. Also make sure the document has more than one frame.

The drawing shows on every frame / frames don't change

The drawing was made before the layer had frames, so it is a still layer. Click a timeline cell on that layer and use Create Blank Frame. Remember: empty cells after a drawing keep showing it (a hold).

Playback is slow or laggy
  • Lower the canvas size: Image › Scale Image to New Size (1080 × 1920 is enough).
  • Merge or hide layers you are not using.
  • In Settings › Configure Krita › Performance, give Krita more RAM and check the animation cache settings.
  • Lower the playback preview quality in the Timeline settings, if your version offers it. The final render is not affected.
  • Close other big apps (browsers eat RAM).
Krita crashed. Is my work lost?

Usually not. Re-open Krita: it offers to restore the autosave. Also save numbered versions with File › Save Incremental Version.

Pen pressure doesn't work

Check Settings › Configure Krita › Tablet settings. Make sure the brush preset uses pressure (most do). Unplug and re-plug the tablet, then restart Krita.
