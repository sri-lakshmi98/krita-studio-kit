# Krita Studio Kit

Free, lightweight tools for making 2D animations and short videos with [Krita](https://krita.org).

- **[booklet/](booklet/)**: a beginner's booklet for 2D animation in Krita (install → draw → animate → timelapse → export Reels → 30-day plan). It can be printed as a PDF.
- **[effect-blender/](effect-blender/)**: a zero-install browser app that adds effects (paper texture, grain, glow, vignette, colour grade, snow/rain/sparkles, titles, fades, camera shake) to Krita exports and saves WebM/PNG. See its [README](effect-blender/README.md).
- **[3d-studio/](3d-studio/)**: Tiny 3D Studio, an easy in-browser 3D maker (shapes, cute presets, materials, lights, keyframe animation, PNG/WebM/GLB/OBJ/STL export). See its [README](3d-studio/README.md).

Plain HTML/CSS/JS with no build step. Open `index.html` or use the GitHub Pages site.
